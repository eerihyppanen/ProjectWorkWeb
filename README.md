# Statistics Portal


## Overview

This project is a **statistics portal** that visualizes Finnish municipal data using an interactive map and dynamic charts.  
The application allows users to explore different datasets, switch visualization types, and inspect municipality-specific information directly from the map.

The focus of the project was on **working with public APIs**, **data visualization**, and **clean frontend structure**, while ensuring cross-browser compatibility and responsive design.

---

## Tech Stack

- **Languages:** HTML, CSS, JavaScript  
- **APIs & Data Sources:**
  - Statistics Finland (Tilastokeskus)
  - OpenStreetMap
  - Google Maps data
- **Frameworks / Libraries:**
  - Leaflet (interactive maps)
  - Frappe Charts (data visualization)
- **Styling:** CSS (Flexbox)

---

## Features

- 🗺️ Interactive map showing municipality-level data
- 📊 Dynamic charts with selectable datasets
- 🔄 Ability to switch between different data layers on the map
- 🧭 Clickable municipalities to view additional charts
- 📈 Chart type selection (line, bar, pie)
- ⬇️ Export charts as SVG images
- 🌗 Default mode and dark mode
- 📘 Built-in manual (modal) explaining how to use the application

---

## Application Structure

The application follows a clear and simple structure:


- JavaScript logic is separated into its own folder
- Styling is handled entirely with CSS
- The app uses a single HTML file as the entry point

---
